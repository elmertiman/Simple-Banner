HOW TO USE
================================================================================

INSTALLATION
------------
1. Copy 'simple-banner' folder to /wp-content/plugins/
2. Activate via WordPress Admin → Plugins
3. Look for "Simple Banners" in admin menu

CREATE BANNER
-------------
1. Simple Banners → Add New
2. Enter title (e.g., "Homepage Hero")
3. Click "Add Image" button
4. Upload/select 2-3 images
5. Add URL links (optional)
6. Customize colors in sidebar
7. Click "Publish"
8. Copy shortcode

USE SHORTCODE
-------------
1. Edit any page/post
2. Add shortcode block (Gutenberg)
3. Paste: [simple_banner id="123"]
4. Publish page
5. View on frontend

MANAGE IMAGES
-------------
- Drag handle (≡) to reorder
- Eye icon to activate/deactivate
- Image icon to change image
- Trash icon to delete
- URL field to add links

CUSTOMIZE
---------
- Controls Color: Color picker (arrows)
- Indicators Color: Color picker (dots)
- Autoplay: Checkbox
- Interval: Number input (milliseconds)

================================================================================
DATABASE STRUCTURE
================================================================================

Tables Used (WordPress Core)
-----------------------------
wp_posts
  - Stores banner instances (post_type = 'simple_banner')
  
wp_postmeta
  - _banner_images (array of image data)
  - _banner_controls_color (hex color)
  - _banner_indicators_color (hex color)
  - _banner_autoplay (1 or 0)
  - _banner_interval (milliseconds)

Image Data Structure
--------------------
Array of:
{
  image_id: 123,
  image_url: 'https://site.com/image.jpg',
  link_url: 'https://site.com/page',
  active: true/false
}
