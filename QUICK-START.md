# Simple Banner - Quick Start Guide

## 🚀 Installation in 3 Steps

1. **Upload Plugin**
   - Copy the `simple-banner` folder to `/wp-content/plugins/`
   - Or upload via WordPress Admin → Plugins → Add New → Upload Plugin

2. **Activate**
   - Go to Plugins in WordPress admin
   - Find "Simple Banner" and click Activate

3. **Create Your First Banner**
   - You'll see "Simple Banners" in the admin menu
   - Click "Add New"

## 📸 Creating Your First Banner

### Step 1: Basic Setup
```
1. Go to Simple Banners → Add New
2. Enter a title (e.g., "Homepage Banner")
3. Click "Add Image" button
```

### Step 2: Add Images
```
1. Click "Add Image"
2. Upload images or select from library
3. Add a URL link (optional)
4. Add more images by clicking "Add Image" again
```

### Step 3: Customize
```
1. In the right sidebar, customize:
   - Controls Color (arrow buttons)
   - Indicators Color (dots)
   - Enable/disable image rotation
   - Set rotation speed (seconds)
2. Click "Publish"
```

### Step 4: Use Shortcode
```
1. Copy the shortcode from the sidebar or list view
2. Paste into any page/post
   Example: [simple_banner id="123"]
3. Done! 🎉
```

## 🎨 Common Use Cases

### Homepage Hero Banner
- Add 3-5 high-quality images
- Link each to important pages
- Enable image rotation with 5 seconds speed
- Use white controls and indicators

### Product Showcase
- Add product images
- Link to product pages
- Disable image rotation (let users control)
- Match colors to your brand

### Gallery Slider
- Add multiple images
- No links needed
- Enable image rotation
- Faster speed (3 seconds)

## ⚙️ Managing Images

| Action | How To |
|--------|--------|
| **Reorder** | Drag & drop using the ≡ handle |
| **Edit Link** | Type URL in the "Link URL" field |
| **Deactivate** | Click the eye icon (keeps image saved) |
| **Activate** | Click the eye icon on inactive image |
| **Delete** | Click trash icon (permanently removes) |
| **Change Image** | Click image icon to select different image |

## 🎯 Tips & Tricks

### Optimal Image Sizes
- **Desktop**: 1920x1080px (16:9 ratio)
- **Mobile**: Will auto-scale responsively
- **File Size**: Keep under 500KB for fast loading
- **Format**: JPEG for photos, PNG for graphics

### Best Practices
1. ✅ Use 3-5 images per banner (not too many)
2. ✅ Keep image sizes consistent
3. ✅ Optimize images before uploading
4. ✅ Test on mobile devices
5. ✅ Use meaningful image alt text

### Color Customization
```
White (#ffffff) - Works on dark images
Black (#000000) - Works on light images
Brand Colors - Match your site theme
```

### Performance
- Deactivate unused images instead of deleting
- Keep only necessary images active
- Use image optimization plugins
- Consider lazy loading for multiple banners

## 🔧 Troubleshooting

### Images not showing?
- Check if images are marked as "Active" (eye icon)
- Verify correct shortcode ID
- Clear cache if using caching plugin

### Controls not visible?
- Try different control colors (white/black)
- Check if images are too small
- Verify Bootstrap 5 is loading

### Shortcode not working?
- Verify banner is published (not draft)
- Check shortcode format: [simple_banner id="123"]
- Ensure shortcode support is enabled

- Images
- Colors
- Autoplay settings
- Slide intervals
